🎥 Видеосабақ

Видеосабақты көріп, тақырыпты меңгеріп ал.

📚 Тақырыптық анықтама

Екі теріс санды қосқанда олардың модульдерін қосып, шыққан санның алдына «−» таңбасын қоямыз.

Ереже:

(−a) + (−b) = −(a + b)

Мысалы:
−5 + (−3) = −(5 + 3) = −8
−12 + (−7) = −19

Екі теріс санның қосындысы әрқашан теріс сан болады. Қосындының модулі қосылғыштардың модульдерінің қосындысына тең.

Координаталық түзуде теріс санды қосу үшін бастапқы нүктеден солға қарай қажетті бірлік санына жылжимыз. Ал 0 санын қосқанда сан өзгермейді: a + 0 = a.

−3 + (−4) = −7
