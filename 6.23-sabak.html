📚 Тақырыптық анықтама

Рационал сандарды бөлгенде алдымен бөліндінің таңбасын, содан кейін оның модулін анықтаймыз. Таңбалары бірдей сандардың бөліндісі оң, ал таңбалары әртүрлі сандардың бөліндісі теріс болады.

Таңбалар ережесі:

(+) : (+) = (+)
(−) : (−) = (+)
(+) : (−) = (−)
(−) : (+) = (−)

Бөліндінің модулін табу үшін бөлінгіштің модулін бөлгіштің модуліне бөлеміз. Мысалы: −24 : 6 = −4, ал −24 : (−6) = 4.

0 санын нөлден өзге кез келген санға бөлуге болады: 0 : a = 0. Бірақ санды 0-ге бөлуге болмайды.
