28-сабақ. Жақшаларды ашу. Коэффициент

6-сынып • Математика

🎥 Видеосабақ

Видеосабақты көріп, тақырыпты меңгеріп ал.

📚 Тақырыптық анықтама

Жақша ішіндегі өрнекті оған тең жақшасыз өрнекпен алмастыру жақшаларды ашу деп аталады. Егер жақша алдында «+» таңбасы тұрса, жақша ішіндегі қосылғыштардың таңбалары өзгермейді.

Мысалы:

a + (−b + c − d) = a − b + c − d

Егер жақша алдында «−» таңбасы тұрса, жақша ішіндегі әрбір қосылғыштың таңбасы қарама-қарсы таңбаға өзгереді.

Мысалы:

a − (b − c + d) = a − b + c − d

Жақша алдында көбейткіш тұрса, көбейтудің үлестірімділік қасиеті қолданылады. Көбейткіш жақша ішіндегі әрбір қосылғышқа көбейтіледі: a(b + c) = ab + ac.

Әріпті өрнектегі сан көбейткіш коэффициент деп аталады. Мысалы, −7ab өрнегінің коэффициенті −7. Егер сан жазылмаса, коэффициент 1, ал өрнек алдында «−» тұрса, коэффициент −1 болады.
