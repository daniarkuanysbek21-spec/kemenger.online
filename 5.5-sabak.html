5-сабақ. Натурал сандарды көбейту және бөлу. Бөліндінің негізгі қасиеті

5-сынып • Математика

🎥 Видеосабақ

Видеосабақты көріп, тақырыпты меңгеріп ал.

📚 Тақырыптық анықтама

Бірдей қосылғыштардың қосындысын қысқаша көбейтінді түрінде жазуға болады. a санын b санына көбейту дегеніміз — әрқайсысы a-ға тең b қосылғыштың қосындысын табу.

a · b = a + a + a + ... + a

Мысалы: 3 · 7 = 21.

Кез келген a саны үшін: a · 1 = a, 1 · a = a, a · 0 = 0, 0 · a = 0.

Екі санның көбейтіндісі және көбейткіштердің біреуі белгілі болса, екінші көбейткішті табу амалы бөлу деп аталады. Мысалы: 54 : 18 = 3. Мұнда 54 — бөлінгіш, 18 — бөлгіш, 3 — бөлінді. Нөлге бөлуге болмайды.

Бөліндінің негізгі қасиеті: бөлінгішті де, бөлгішті де бірдей натурал санға көбейткенде немесе бөлгенде бөліндінің мәні өзгермейді.

Мысалы: 60 : 15 = 120 : 30 = 20 : 5 = 4.
