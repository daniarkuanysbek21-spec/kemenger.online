📚 Тақырыптық анықтама

Санның модулі — координаталық түзудегі осы санға сәйкес нүктенің санақ басынан, яғни O(0) нүктесінен қашықтығы. Санның модулі |a| түрінде жазылады.

Оң санның модулі сол санның өзіне тең: |7| = 7. Теріс санның модулі оған қарама-қарсы оң санға тең: |−7| = 7. Ал нөлдің модулі |0| = 0.

Қарама-қарсы сандардың модульдері тең: |−a| = |a|. Сондықтан санның модулі ешқашан теріс болмайды.

Есте сақта:

a > 0 болса, |a| = a;
a = 0 болса, |a| = 0;
a < 0 болса, |a| = −a.
