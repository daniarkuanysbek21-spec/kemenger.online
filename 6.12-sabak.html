12-сабақ. Бүтін сандар. Рационал сандар

6-сынып • Математика

🎥 Видеосабақ

Видеосабақты көріп, тақырыпты меңгеріп ал.

📚 Тақырыптық анықтама

Натурал сандар, оларға қарама-қарсы сандар және 0 саны бүтін сандар деп аталады. Бүтін сандар жиыны Z әрпімен белгіленеді.

Z = { ..., −4, −3, −2, −1, 0, 1, 2, 3, 4, ... }

Натурал сандар жиыны N бүтін сандар жиынының бір бөлігі: N ⊂ Z.

Рационал сан — m n түрінде жазылатын сан. Мұндағы m — бүтін сан, n — натурал сан. Рационал сандар жиыны Q әрпімен белгіленеді.

Бүтін сандар да рационал сандар болып табылады, себебі кез келген бүтін санды бөлімі 1 болатын бөлшек түрінде жазуға болады. Сондықтан N ⊂ Z ⊂ Q.
